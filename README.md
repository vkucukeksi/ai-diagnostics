# 🧠 AI Diagnostics & Security Analysis Toolkit

This project demonstrates how LLMs can assist in infrastructure diagnostics and security analysis.

---

## 🚀 Overview

The goal of this project is to explore how AI can:

- Analyse system and infrastructure data  
- Help identify root causes of issues  
- Highlight potential security risks  
- Provide clear, actionable recommendations

---

## 🔑 API Requirements

This project includes optional AI-powered analysis using the OpenAI API.

To enable this feature, you will need:

An OpenAI API key
Active billing / available credits

Set your API key in PowerShell before running:

$env:OPENAI_API_KEY="your-api-key"

If no API credits are available, the AI analysis step will fail. The core data collection and analysis scripts will still function as expected.
